# ROADMAP: Сервис сокращения ссылок с аналитикой переходов (URL Shortener & Click Analytics Service)

## 📌 Паспорт проекта
- **Название проекта:** TinyURL & Analytics Service (PulseLink)
- **Тема проекта:** Высоконагруженный сервис управления сокращенными ссылками и асинхронной аналитики переходов.
- **Описание сути проекта:** Отказоустойчивый распределенный бэкенд-сервис, решающий две ключевые задачи: мгновенное перенаправление пользователей по коротким URL с минимальной субмиллисекундной задержкой (через Cache-Aside в Redis) и сбор аналитики по каждому переходу (геолокация, User-Agent, referer, временные ряды) в асинхронном неблокирующем режиме через RabbitMQ (Producer-Consumer). Архитектура состоит из REST API сервиса, брокера сообщений, воркера обработки аналитических событий, кэширующего слоя Redis и реляционной СУБД PostgreSQL.
